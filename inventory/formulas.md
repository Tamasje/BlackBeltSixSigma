### 20260529_ottoy_Acceptance Sampling - Further Reading.pdf

#### Single-stage sampling plan for attributes - OC curve (source/course/Les 2/20260529_ottoy_Acceptance Sampling - Further Reading.pdf p. 4, S04)

```
OC(p) = P(X<=c | p) = H(c;N,M_p,n) with M_p = [N*p]
```
- `p`: lot fraction defectives
- `c`: acceptance number
- `N`: lot size
- `n`: sample size
- `M_p`: number of defectives in the lot = [N*p] (nearest integer)
- `H`: hypergeometric c.d.f. (in R: phyper(c,M,N-M,n))
- Conditions: AQL = p such that OC(p) = 1-alpha (=95% stated as the default); LQL = p such that OC(p) = beta (=10% stated as the default). Specifying both AQL and LQL uniquely characterizes the (n,c) plan.

#### Double sampling plan for attributes - OC, Pi(p), ASN(p) (source/course/Les 2/20260529_ottoy_Acceptance Sampling - Further Reading.pdf p. 5, S04)

```
OC(p) = H(c1;H,M_p,n1) + SUM_{j=c1+1}^{c2-1} h(j;N,M_p,n1) * H(c3-j; N-n1, M_p-j, n2);  Pi(p) = H(c1;N,M_p,n1) + 1 - H(c2-1;N,M_p,n1);  ASN(p) = n1*Pi(p) + (n1+n2)*(1-Pi(p))
```
- `h`: hypergeometric p.m.f.
- `H`: hypergeometric c.d.f.
- `Pi(p)`: probability of reaching a decision after the first sample
- `ASN`: average sample number
- `n1,c1,c2`: first-stage sample size and limits
- `n2,c3`: second-stage sample size and limit
- Conditions: as printed; the first OC(p) term uses 'H' as the population-size argument of H(.), which is inconsistent with the N used in the Pi(p) formula directly below (see ambiguities)

#### SPRT likelihood ratio and log-likelihood (Wald sequential probability ratio test) (source/course/Les 2/20260529_ottoy_Acceptance Sampling - Further Reading.pdf p. 6, S04)

```
Lambda(X_n,n;p0,pt) = (pt/p0)^X_n * ((1-pt)/(1-p0))^(n-X_n);  log(Lambda) = X_n*( log(pt/p0) - log((1-pt)/(1-p0)) ) + n*log((1-p0)/(1-pt))
```
- `X_n`: number of defectives found after n inspections
- `p0`: AQL fraction defective
- `pt`: LQL fraction defective (course also writes p1/pt)
- Conditions: stop and accept if log(Lambda) < log(A) (A = beta/(1-alpha) < 1); stop and reject if log(Lambda) > log(B) (B = (1-beta)/alpha > 1); PR = 1-OC(p0) = alpha (producer's risk), CR = OC(pt) = beta (consumer's risk). For binomial instead of hypergeometric, OK if lot size is large compared to sample size.

#### SPRT reject/accept boundaries (graphical form Xn vs n) (source/course/Les 2/20260529_ottoy_Acceptance Sampling - Further Reading.pdf p. 7, S04)

```
Reject: X_n >= h2 + s*n, with h2 = log((1-beta)/alpha) / log( pt*(1-p0) / (p0*(1-pt)) )  and  s = log((1-p0)/(1-pt)) / log( pt*(1-p0) / (p0*(1-pt)) ), both > 0.  Accept: X_n <= -h1 + s*n, with h1 = log((1-alpha)/beta) / log( pt*(1-p0) / (p0*(1-pt)) ) > 0
```
- `h1,h2`: intercepts of the accept/reject lines
- `s`: common slope of the accept/reject lines
- Conditions: example given: p0=0.01, pt=0.05, alpha=beta=0.05 => h1=h2=1.78 and s=0.025

#### SPRT OC and ASN functions (source/course/Les 2/20260529_ottoy_Acceptance Sampling - Further Reading.pdf p. 8, S04)

```
p(tau) = [1 - ((1-pt)/(1-p0))^tau] / [ (pt/p0)^tau - ((1-pt)/(1-p0))^tau ];  ASN(p) = { [OC(p)*log(beta/(1-alpha)) + (1-OC(p))*log((1-beta)/alpha)] / [p*log(pt/p0) + (1-p)*log((1-pt)/(1-p0))]  if p != s ;  h1*h2/(s*(1-s))  if p = s };  OC(p(tau)) = [ ((1-beta)/alpha)^tau - 1 ] / [ ((1-beta)/alpha)^tau - (beta/(1-alpha))^tau ]
```
- `tau`: parameter indexing points on the OC curve (tau=-infinity: p(tau)=1; tau=-1: p(tau)=pt; tau=0: p(tau)=s in [p0,pt]; tau=1: p(tau)=p0; tau=+infinity: p(tau)=0)
- Conditions: given without proof; verifiable by simulation with the course's R-function OC_SPRT.TXT

#### Single sampling plan for variables - inspection statistic and OC curve (source/course/Les 2/20260529_ottoy_Acceptance Sampling - Further Reading.pdf p. 9, S04)

```
Q = (Xbar - xi)/s;  accept the lot if Q >= k  <=>  Xbar - k*s >= xi;  OC(p) ~= 1 - Phi( (z_p+k)*sqrt(n) / (1+k^2/2)^(1/2) )
```
- `Xbar`: sample mean
- `s`: sample standard deviation
- `xi`: lower specification limit
- `k`: acceptance constant (counterpart of c for attribute plans)
- `z_p`: standard-normal quantile for fraction defective p
- `n`: sample size
- `Phi`: standard normal c.d.f.
- Conditions: lot acceptable if p <= AQL = p0 <=> xi <= X_p0; given n, k can be found so that OC(AQL=p0) = 1-alpha: k ~= t(1-alpha,p0,n)

#### Variable sampling plan: k and n from AQL and LQL (source/course/Les 2/20260529_ottoy_Acceptance Sampling - Further Reading.pdf p. 9, S04)

```
k = (z_pt*z_alpha + z_p0*z_beta) / (z_(1-alpha) + z_(1-beta));  n = (z_(1-alpha)+z_(1-beta))^2 * (1+k^2/2) / (z_pt - z_p0)^2
```
- `p0`: AQL
- `pt`: LQL
- `alpha`: producer's risk (OC(AQL=p0)=1-alpha)
- `beta`: consumer's risk (OC(LQL=pt)=beta)
- Conditions: derivation left as an exercise; worked example: (p0=0.5%, 1-alpha=95%) and (pt=3.5%, beta=5%) => k=2.1939, n=64

#### Rectifying inspection: AOQ, AOQL, ATI (source/course/Les 2/20260529_ottoy_Acceptance Sampling - Further Reading.pdf p. 10, S04)

```
AOQ(p) = p*OC(p)*(1 - (n/N)*R_s*) ~= p*OC(p)  [for n<<N], with R_s* = H(c-1;N-1,[Np]-1,n-1) / H(c;N,[Np],n);  AOQL(p) = max_p AOQ(p);  ATI(p) = n*OC(p) + N*(1-OC(p))
```
- `AOQ`: Average Outgoing Quality
- `AOQL`: Average Outgoing Quality Limit
- `ATI`: Average Total Inspection effort
- Conditions: assumes non-destructive tests, defectives found are replaced by good ones, and rejected lots undergo full rectification (100% inspection with replacement); formula for R_s* assumes single-stage sampling

#### Skip-lot qualification probability (worked example) (source/course/Les 2/20260529_ottoy_Acceptance Sampling - Further Reading.pdf p. 11, S04)

```
P_q = B(3;640,p) * B^2(0;80,p)   (B = binomial c.d.f.)
```
- `P_q`: probability of qualifying for the skip-lot state
- `p`: overall probability of producing a defective item
- Conditions: worked example: plan (80,2) on lots of size 1000, AQL=1%, assuming the last 10 lots were accepted; condition = first 8 samples have <=3 defectives total AND last two samples are defect-free

#### Deming's inspection criterion - total quality cost (source/course/Les 2/20260529_ottoy_Acceptance Sampling - Further Reading.pdf p. 14, S04)

```
TC = C1 + C2 + C3;  C1 = n*k1/q;  C2 = (N-n)*(1-Q)*k1/q;  C3 = (N-n)*p''*Q*k2;  TC = N*k1*[ 1/q + Q*(k2/k1)*(1-n/N)*(p'' - (k1/k2)*(1/q)) ]
```
- `n`: sample size
- `N`: lot size
- `q`: 1-p
- `k1`: unit inspection cost
- `k2`: unit cost of an assembly failure (dismantle/repair/reassemble)
- `Q`: probability of accepting a lot on average (= OC(p))
- `p''`: average fraction defectives in lots passing inspection
- Conditions: parts delivered in lots of size N, single-stage attribute plan (n,Ac); rejected lots are screened and fully rectified; assumes k1 << k2

#### Deming's break-even rule (source/course/Les 2/20260529_ottoy_Acceptance Sampling - Further Reading.pdf p. 15, S04)

```
if p < k1/k2 then TC is minimal for n=0 (no inspection); if p > k1/k2 then TC is minimal for n=N (screening); k1/k2 is called the break-even quality
```
- Conditions: proved via an R-function referenced as DEMING.TXT in the course; assumes the process is stable at percentage defectives p

#### Deming's model - Q and p'' as sums over the lot's defect count D (source/course/Les 2/20260529_ottoy_Acceptance Sampling - Further Reading.pdf p. 15, S04)

```
Q = OC(p) = SUM_{D=0}^{N} pi_D * beta_D ;  p'' = SUM_{D=0}^{N} (pi_D/beta_D) * SUM_{j=0}^{Ac} beta_j*(D-j)/(N-n)  >  SUM_{D=0}^{N} (pi_D/beta_D) * SUM_{j=0}^{Ac} beta_j*D/N = SUM_{D=0}^{N} pi_D*D/N = p
```
- `pi_D`: probability of exactly D defectives in the lot = binomial = b(D;N,p)
- `beta_D`: probability of accepting a lot with D defectives = hypergeometric = H(Ac;N,D,n)
- Conditions: shown to demonstrate p'' > p, i.e. lots that pass inspection are on average worse than the incoming lot quality p; see course R-functions OC_SAI.TXT and OQ_SAI.TXT

#### Central limit theorem statement (as printed) (source/course/Les 2/20260529_ottoy_Acceptance Sampling.pdf p. 9, S04)

```
Xi IID => SUM(Xi) ~ N(mu,sigma)
```
- `Xi`: identically and independently distributed inputs
- `mu`: mean
- `sigma`: standard deviation
- Conditions: used to motivate why the normal distribution is prevalent for process outputs

#### Process capability index Cpk (source/course/Les 2/20260529_ottoy_Acceptance Sampling.pdf p. 10, S04)

```
C_pk = min( (X_U - mu)/(3*sigma) , (mu - X_L)/(3*sigma) )
```
- `X_U`: upper specification limit
- `X_L`: lower specification limit
- `mu`: process mean
- `sigma`: process standard deviation
- Conditions: X ~ N(mu,sigma); slide shows X_U - X_L = 6*sigma giving Cpk=1 (99.73% conform, 0.27% defective) and X_U - X_L = 8*sigma giving Cpk=1.33 (99.9937% conform, 63 ppm defective)

#### Normal distribution in Excel (source/course/Les 2/20260529_ottoy_Acceptance Sampling.pdf p. 11, S04)

```
phi(x1) = 1/(sigma*sqrt(2*pi)) * exp(-(x1-mu)^2/(2*sigma^2)) = NORM.DIST(x1,mu,sigma,FALSE); Phi(x2) = INTEGRAL_{-inf}^{x2} phi(x) dx = NORM.DIST(x2,mu,sigma,TRUE); x2 = Phi^-1(p) = X_p = NORM.INV(p,mu,sigma)
```
- `phi`: normal pdf
- `Phi`: normal cdf
- `X_p`: p-th quantile
- Conditions: to generate a pseudo-random normal sample: =NORM.INV(RAND(),MU,SIGMA)

#### Probability of i non-conformities in a lot (binomial) (source/course/Les 2/20260529_ottoy_Acceptance Sampling.pdf p. 12, S04)

```
P[i] = C_N^i * pi^i * (1-pi)^(N-i)
```
- `i`: number of non-conforming items in the lot
- `N`: lot size
- `pi`: process fraction non-conforming
- `C_N^i`: number of combinations of N items taken i at a time
- Conditions: defects occur independently over time (stable process)

#### SRS sampling distribution of number of defectives (hypergeometric, binomial approximation) (source/course/Les 2/20260529_ottoy_Acceptance Sampling.pdf p. 16, S04)

```
P[d=i] = (C_D^i * C_(N-D)^(n-i)) / C_N^n  ~=  C_n^i * pi^i * (1-pi)^(n-i)  (binomial)
```
- `d`: number of defectives found in the sample
- `D`: number of defectives in the lot
- `N`: lot size
- `n`: sample size
- `pi`: D/N = lot fraction defectives
- Conditions: exact distribution is hypergeometric; binomial approximation is used unless the population is small

#### Sampling variance of P (SRS, binomial) (source/course/Les 2/20260529_ottoy_Acceptance Sampling.pdf p. 16, S04)

```
sigma^2[P] = pi*(1-pi)/n
```
- `P`: sample fraction defectives = d/n
- `pi`: lot fraction defectives
- `n`: sample size

#### Pre-stratified sample: unbiasedness and variance of the combined estimator (source/course/Les 2/20260529_ottoy_Acceptance Sampling.pdf p. 17, S04)

```
E[P] = E[P_s] = pi;  sigma^2[P_s] = (W_A*sigma_A^2 + W_B*sigma_B^2)/n;  sigma^2[P] = (W_A*sigma_A^2 + W_B*sigma_B^2 + W_A*W_B*(pi_A-pi_B)^2)/n
```
- `W_A`: population weight of stratum A (=N_A/N)
- `W_B`: population weight of stratum B (=N_B/N)
- `pi_A`: fraction defectives in stratum A
- `pi_B`: fraction defectives in stratum B
- `sigma_A^2`: pi_A*(1-pi_A)
- `sigma_B^2`: pi_B*(1-pi_B)
- `sigma^2`: pi*(1-pi)
- `n`: total sample size
- `P_s`: proportional pre-stratified estimator = W_A*P_A + W_B*P_B
- `P`: SRS estimator
- Conditions: proportional pre-stratification: n_A = W_A*n, n_B = W_B*n

#### General two-stratum mean/variance decomposition (used to derive the stratification formulas) (source/course/Les 2/20260529_ottoy_Acceptance Sampling.pdf p. 17, S04)

```
mu = W_A*mu_A + W_B*mu_B;  sigma^2 = W_A*sigma_A^2 + W_B*sigma_B^2 + W_A*(mu_A-mu)^2 + W_B*(mu_B-mu)^2
```
- `mu_A`: mean of stratum A
- `mu_B`: mean of stratum B
- Conditions: given in the notes as the general identity behind the page-17 formulas

#### Optimal vs proportional pre-stratification sample allocation (source/course/Les 2/20260529_ottoy_Acceptance Sampling.pdf p. 18, S04)

```
n_A = (W_A*sigma_A)/(W_A*sigma_A + W_B*sigma_B) * n  (idem for n_B), with sigma_A = sqrt(pi_A*(1-pi_A)) (idem sigma_B). Proportional stratification: n_A/n_B = W_A/W_B. Optimal stratification: n_A/n_B = (W_A*sigma_A)/(W_B*sigma_B)
```
- `n_A`: sample size drawn from stratum A
- `n_B`: sample size drawn from stratum B
- Conditions: optimal stratification requires prior knowledge of pi_A, pi_B (e.g. via a prior sample from each stratum)

#### Distribution of the number of defectives in a (pre-)stratified sample (source/course/Les 2/20260529_ottoy_Acceptance Sampling.pdf p. 18, S04)

```
P[d_s=i] = SUM_{k=0}^{i} [ C_nA^k * piA^k * (1-piA)^(nA-k) * C_nB^(i-k) * piB^(i-k) * (1-piB)^(nB-i+k) ]
```
- `d_s`: number of defectives in the stratified sample
- `n_A`: sample size from stratum A
- `n_B`: sample size from stratum B
- Conditions: based on binomial probabilities within each stratum; hypergeometric to be exact

#### Two equally-sized normally distributed strata: variance of the population and of the sample mean (source/course/Les 2/20260529_ottoy_Acceptance Sampling.pdf p. 19, S04)

```
sigma^2 = sigma_S^2 + (mu_A-mu_B)^2/4;  E[Xbar] = E[Xbar_S] = mu;  sigma^2[Xbar_S] = sigma_S^2/n;  sigma^2[Xbar] = sigma^2[Xbar_S] + (mu_A-mu_B)^2/(4n)
```
- `sigma_S^2`: common within-stratum variance
- `mu_A`: mean of stratum A
- `mu_B`: mean of stratum B
- `Xbar`: SRS sample mean (printed as X with an overline)
- `Xbar_S`: proportionally pre-stratified sample mean

#### Cluster-sampling probability of zero defectives (worked extreme-concentration case) (source/course/Les 2/20260529_ottoy_Acceptance Sampling.pdf p. 20, S04)

```
P[d_C=0] = ( C_9^2 * C_100^5 * C_100^5 + 9 * C_100^5 * C_80^5 ) / ( C_10^2 * C_100^5 * C_100^5 ) = 86%
```
- `d_C`: number of defectives found in the cluster sample

- `C_100^5`: ways to pick 5 of the 100 boxes on a palette
- `C_80^5`: ways to pick 5 defect-free boxes out of the 80 defect-free boxes on the one palette that holds all 20 defective boxes

#### Long-run equivalence of SRS and cluster-sample binomial probabilities (3-defectives example) (source/course/Les 2/20260529_ottoy_Acceptance Sampling.pdf p. 20, S04)

```

```
- `pi`: per-item fraction defective (stable process)
- Conditions: shown to illustrate that, when the lots come from a stable process with a given pi, cluster sampling and SRS give the same (binomial) sampling distribution in the long run

#### Non-response bias / variance of the sample mean (source/course/Les 2/20260529_ottoy_Acceptance Sampling.pdf p. 22, S04)

```
sigma^2[Xbar] = sigma^2/n
```
- `Xbar`: sample mean
- `sigma^2`: population variance
- `n`: sample size
- Conditions: used to explain that sampling error (random) and bias (systematic, from an unrepresentative frame) both contribute to total error; a small SRS from the full population can beat a large SRS from a biased frame

#### Variable-sampling k-factor t(alpha,beta,n) (main-deck derivation) (source/course/Les 2/20260529_ottoy_Acceptance Sampling.pdf p. 27, S04)

```
t(alpha,beta,n) = [ Z_(1-beta) + Z_(1-alpha)*sqrt( 1/n + Z^2_(1-beta)/(2n) - Z^2_(1-alpha)/(2n^2) ) ] / [ 1 - Z^2_(1-alpha)/(2n) ];  hence t(1-alpha,p0,n) = [ Z_(1-p0) + Z_alpha*sqrt( 1/n + Z^2_(1-p0)/(2n) - Z^2_alpha/(2n^2) ) ] / [ 1 - Z^2_alpha/(2n) ]
```
- `Z`: standard normal N(0,1) quantile
- Conditions: valid for sufficiently large n; used so that with probability 1-alpha at least a fraction 1-beta of the population is >= Xbar - k*s

```
H0: pi = pi0 vs. (DZ) HA: pi != pi0 of (EZ) HA: pi > (<) pi0; z = (p - pi0) / sqrt(pi0(1-pi0)/n); met continuïteitscorrectie: z = (p ± 1/(2n) - pi0) / sqrt(pi0(1-pi0)/n)  (+ links, - rechts staart; let op bij DZ)
```
- `p`: steekproefproportie
- `pi0`: getoetste waarde
- `n`: steekproefgrootte
- Conditions: Z ~ N(0,1) slechts benaderd geldig, voorwaarde n*pi0 > 5; indien n*pi0 < 5, werk met exacte distributie van P onder H0 (bij DZ via BI)

#### chi²-test voor sigma (testrecept) (source/course/Les 2/20260529_ottoy_Test Recipes - Further Reading (Dutch).pdf p. 11, S03)

```
H0: sigma = sigma0 vs. (DZ) HA: sigma != sigma0 of (EZ) HA: sigma > (<) sigma0; statistiek = (n-1)*s²/sigma0²
```
- `s²`: steekproefvariantie
- `sigma0`: getoetste waarde
- `n`: steekproefgrootte
- Conditions: parametrische test: X normaal verdeeld; dan statistiek ~ chi²(n-1); test is niet robuust (sterk gevoelig aan niet-normaliteit van X)

#### F-distributie (definitie en kritische waarden) (source/course/Les 2/20260529_ottoy_Test Recipes - Further Reading (Dutch).pdf p. 12, S03)

```
X ~ chi²(n), Y ~ chi²(m), X en Y onafhankelijk => (X/n)/(Y/m) ~ F(n,m); stelling: RS1 -> n1,s1²; RS2 -> n2,s2² onafhankelijk => (s1²/sigma1²)/(s2²/sigma2²) ~ F(n1-1,n2-1); kritische waarden: F_alpha(n,m) = 1/F_(1-alpha)(m,n); E(F(n,m)) = m/(m-2) (m>2); mode(F(n,m)) = (n-2)m/(n(m+2)) (n>2)
```
- `n,m`: vrijheidsgraden teller resp. noemer
- Conditions: n.v.t.

#### F-test voor sigma1/sigma2 (testrecept) (source/course/Les 2/20260529_ottoy_Test Recipes - Further Reading (Dutch).pdf p. 13, S03)

```
H0: sigma1=sigma2 vs. (DZ) HA: sigma1 != sigma2 of (EZ) HA: sigma1 > (<) sigma2; F = s1²/s2² of F = s2²/s1²
```
- `s1,s2`: steekproefspreidingen van RS1 (n1) en RS2 (n2), beide onafhankelijk
- Conditions: parametrische test: X1,X2 normaal verdeeld; dan F ~ F(n1-1,n2-1) of F(n2-1,n1-1) (keuze van F wordt gemaakt rekening houdend met beschikbare kritische waarden in de tabellen, enkel voor probabiliteiten < 0.5); test is niet robuust

#### chi²-test 'goodness of fit' (testrecept) (source/course/Les 2/20260529_ottoy_Test Recipes - Further Reading (Dutch).pdf p. 16, S03)

```
H0: distributie van X heeft vooropgestelde gedaante; statistiek = som_k=1^r (e_k - n_k)² / e_k, waarbij e_k = n*pi_k, pi_k = P[X in klasse k]
```
- `n_k`: waargenomen absolute frequentie in klasse k
- `e_k`: verwachte absolute frequentie in klasse k onder H0
- `r`: aantal klassen
- `g`: aantal geschatte parameters (momentenmethode)
- Conditions: niet parametrisch: statistiek ~ chi²(r-g-1), slechts benaderd, voorwaarde e_k > 5; test is eenzijdig (EZ)

#### chi²-test 'contingency tables' (testrecept) (source/course/Les 2/20260529_ottoy_Test Recipes - Further Reading (Dutch).pdf p. 19, S03)

```
H0: X en Y zijn onafhankelijk; statistiek = som_k=1^r som_l=1^s (n_kl - e_kl)² / e_kl, waarbij e_kl = n*pi_kl (onder H0: e_kl = n*pi_k.*pi_.l), geschat via pi_k. ≅ n_k./n en pi_.l ≅ n_.l/n zodat e_kl = n_k.*n_.l/n
```
- `n_kl`: waargenomen frequentie in cel (k,l)
- `e_kl`: verwachte frequentie in cel (k,l)
- `r,s`: aantal klassen voor X resp. Y
- Conditions: niet parametrisch: statistiek ~ chi²(rs-g-1), g=(r-1)(s-1)... vrijheidsgraden = (r-1)(s-1) [zoals afgedrukt: 'g = aantal te schatten parameters => aantal vrijheidsgraden = (r-1)(s-1)']; benaderd, voorwaarde e_kl > 5; bij 2x2-tabel: continuïteitscorrectie van Yates: n_ij < e_ij => n_ij + 1/2; n_ij > e_ij => n_ij - 1/2; test is EZ

#### Wilcoxon-Mann-Whitney-test (source/course/Les 2/20260529_ottoy_Test Recipes - Further Reading (Dutch).pdf p. 21, S03)

```
H0: nu1=nu2 vs. (DZ) HA: nu1 != nu2 of (EZ) HA: nu1 > (<) nu2; statistiek W_X1 = som van rangen geassocieerd aan X1-waarden (alle N=n1+n2 waarden samen gerangschikt); W_X1 discreet en symmetrisch; E(W_X1) = n1(N+1)/2; sigma²(W_X1) = n1*n2*(N+1)/12
```
- `n1,n2`: steekproefgrootten (n1=m, n2=n conventie m<=n)
- `N`: n1+n2
- Conditions: niet parametrische test: vorm van X1,X2 niet vooropgesteld, wel: vorm van X1 en X2 gelijk; voor n1,n2<=10 tabel met kritische waarden; voor grotere n1,n2 benaderd normaal (Z-test, +continuïteitscorrectie); ties: gemiddelde rang toekennen

#### Wilcoxon signed ranks-test (source/course/Les 2/20260529_ottoy_Test Recipes - Further Reading (Dutch).pdf p. 23, S03)

```
H0: nu1=nu2 vs. (DZ) HA: nu1 != nu2 of (EZ) HA: nu1 > (<) nu2; verschillen v_i = x1_i - x2_i, rangschikken in absolute waarde; statistiek T+ = som van rangen geassocieerd aan positieve verschillen; T+ discreet en symmetrisch; E(T+) = n(n+1)/4; sigma²(T+) = n(n+1)(2n+1)/24
```
- `n`: aantal paren (na eliminatie van v_i=0)
- Conditions: niet parametrisch: vorm X1,X2 niet vooropgesteld, wel gelijke vorm; voor n<=15 tabel met kritische waarden (notatie n=N); voor n>15 T+ benaderd normaal (Z-test +continuïteitscorrectie); twee soorten ties: v_i=0 elimineren en n aanpassen; opeenvolgende gelijke abs. waarden: gemiddelde rang

#### Runs-test (Wald-Wolfowitz-test) (source/course/Les 2/20260529_ottoy_Test Recipes - Further Reading (Dutch).pdf p. 25, S03)

```
H0: het steekproefmechanisme leidt tot RS; statistiek = aantal runs R in de steekproef (run = reeks opeenvolgende waarden langs zelfde kant van de mediaan); E(R) ≈ (n+2)/2; sigma²(R) ≈ (n-1)/4
```
- `R`: aantal runs
- `n`: steekproefgrootte
- Conditions: niet parametrisch, geen voorwaarde op distributie van X; R heeft discrete distributie (1<=R<=n); als n voldoende groot, R benaderd normaal => Z-test toepasbaar

- Conditions: E[MS_E] = sigma^2, unbiased

#### Variance/covariance of coefficient estimators (simple regression) (source/course/Les 3/20260605_de vuyst_BB_Regression.pdf p. 29, S05)

```
Var[beta0hat] = sigma^2 (1/n + xbar^2/S_xx) ; Var[beta1hat] = sigma^2/S_xx ; Cov[beta0hat, beta1hat] = -xbar sigma^2 / S_xx
```
- Conditions: beta0hat, beta1hat jointly normal, both independent of SS_E

#### t-test for slope (source/course/Les 3/20260605_de vuyst_BB_Regression.pdf p. 30, S05)

```
(beta1hat - beta_{1,0}) / sqrt(MS_E/S_xx) ~ t_{n-2}
```
- `beta_{1,0}`: reference value under H0
- Conditions: under H0: beta1=beta_{1,0}

#### t-test for intercept (source/course/Les 3/20260605_de vuyst_BB_Regression.pdf p. 31, S05)

```
(beta0hat - beta_{0,0}) / sqrt(MS_E (1/n + xbar^2/S_xx)) ~ t_{n-2}
```
- `beta_{0,0}`: reference value under H0
- Conditions: under H0: beta0=beta_{0,0}

#### F-test for significance of regression (source/course/Les 3/20260605_de vuyst_BB_Regression.pdf p. 33, S05)

```
F = (MS_R/sigma^2) / ((n-2)MS_E/(sigma^2(n-2))) = MS_R/MS_E ~ F_{1,n-2}
```
- Conditions: under H0: beta1=0; Table 11-3 ANOVA layout: Regression SS_R df=1 MS_R F0=MS_R/MS_E; Error SS_E df=n-2 MS_E; Total SS_T df=n-1

#### Confidence interval for slope (source/course/Les 3/20260605_de vuyst_BB_Regression.pdf p. 34, S05)

```
beta1hat + t_{alpha/2,n-2} sqrt(MS_E/S_xx) < beta1 < beta1hat + t_{1-alpha/2,n-2} sqrt(MS_E/S_xx)
```
- Conditions: (1-alpha) confidence interval

#### Confidence interval for intercept (source/course/Les 3/20260605_de vuyst_BB_Regression.pdf p. 34, S05)

```
beta0hat + t_{alpha/2,n-2} sqrt(MS_E (1/n + xbar^2/S_xx)) < beta0 < beta0hat + t_{1-alpha/2,n-2} sqrt(MS_E (1/n + xbar^2/S_xx))
```
- Conditions: (1-alpha) confidence interval

#### Distribution of predicted mean response (source/course/Les 3/20260605_de vuyst_BB_Regression.pdf p. 35, S05)

```
Yhat_0 ~ N( mu_{Y|x0}, sigma^2 (1/n + (xbar-x0)^2/S_xx) )
```
- `Yhat_0`: beta0hat + beta1hat x0

#### Confidence interval for mean response at x0 (source/course/Les 3/20260605_de vuyst_BB_Regression.pdf p. 36, S05)

```
Yhat_0 + t_{alpha/2,n-2} se(Yhat_0) <= mu_{Y|x0} <= Yhat_0 + t_{1-alpha/2,n-2} se(Yhat_0)
```
- `se(Yhat_0)`: sqrt(MS_E (1/n + (xbar-x0)^2/S_xx))

#### Prediction interval for a future observation at x0 (source/course/Les 3/20260605_de vuyst_BB_Regression.pdf p. 38, S05)

```
Yhat_0 + t_{alpha/2,n-2} se(e0) <= Y0 <= Yhat_0 + t_{1-alpha/2,n-2} se(e0)
```
- `se(e0)`: sqrt(MS_E (1 + 1/n + (xbar-x0)^2/S_xx))

#### Multiple linear regression model (population, k regressors) (source/course/Les 3/20260605_de vuyst_BB_Regression.pdf p. 46, S05)

```
Y_i = beta_0 + beta_1 x_{1i} + beta_2 x_{2i} + ... + beta_k x_{ki} + eps_i, i=1,...,n
```
- `eps_i`: N(0,sigma) error
- `k+2`: number of free parameters to estimate

#### Estimated response (multiple regression, k=2) (source/course/Les 3/20260605_de vuyst_BB_Regression.pdf p. 49, S05)

```
Yhat = b0 + b1 X1 + b2 X2
```
- Conditions: k=2 example

#### R^2 (multiple regression) (source/course/Les 3/20260605_de vuyst_BB_Regression.pdf p. 54, S05)

```
R^2 = SSR/SST
```
- `SSR`: explained variability
- `SST`: total variability
- Conditions: R^2 increases whenever a variable is added to the model

#### Adjusted R^2 (multiple regression) (source/course/Les 3/20260605_de vuyst_BB_Regression.pdf p. 56, S05)

```
R^2_adj = 1 - (1-R^2) (n-1)/(n-k-2)
```
- `n`: number of observations
- `k`: number of regressors
- Conditions: only increases when an added variable is sufficiently significant; used to compare different models

#### Estimate of sigma (multiple regression) (source/course/Les 3/20260605_de vuyst_BB_Regression.pdf p. 57, S05)

```
sigmahat = sqrt(MSE) = sqrt(SSE/(n-k-1))
```

#### Second-order polynomial model in two regressors (source/course/Les 3/20260605_de vuyst_BB_Regression.pdf p. 60, S05)

```
Y = beta_0 + beta_1 x1 + beta_2 x2 + beta_12 x1 x2 + beta_11 x1^2 + beta_22 x2^2 + epsilon
```

#### Reparametrised second-order model (acetylene example) (source/course/Les 3/20260605_de vuyst_BB_Regression.pdf p. 60, S05)

```
Y = beta_0 + beta_1 (T-1212.5) + beta_2 (R-12.444) + beta_12 (T-1212.5)(R-12.444) + beta_11 (T-1212.5)^2 + beta_22 (R-12.444)^2 + epsilon
```
- `T`: Temp
- `R`: Ratio

#### F-test for a subset of regression coefficients (source/course/Les 3/20260605_de vuyst_BB_Regression.pdf p. 61, S05)

```
F0 = { [SS_E(RM) - SS_E(FM)] / (k-r) } / { SS_E(FM) / (n-p) }
```
- `RM`: reduced model
- `FM`: full model
- `k-r`: number of coefficients tested = 0
- `n-p`: error df of full model
- Conditions: H0: beta_{r+1}=beta_{r+2}=...=beta_k=0 ; H1: at least one beta != 0

### Six Sigma For Dummies.pdf

#### Breakthrough equation (source/course/Les 4/Six Sigma For Dummies.pdf p. 46, S07)

```
Y = f(X) + ε
```
- `Y`: the outcome, the result you desire or need
- `X`: represents the inputs, factors, or pieces that are needed to create the outcome (can have several Xs)
- `f`: the function, the way or process by which the inputs are transformed into the outcome
- `ε`: the presence of error, the uncertainty in depending upon the Xs and the transformation function to actually create the desired outcome
- Conditions: Called the breakthrough equation. Book states: 'Everything is deterministic. All outcomes are a result of some process or function acting on the inputs.'

#### Mean (source/course/Les 4/Six Sigma For Dummies.pdf p. 107, S07)

```
x̄ = Σxᵢ / n
```
- `x̄`: the calculated mean (pronounced ex bar)
- `Σ`: Greek capital letter sigma, sum up all the individual measurements
- `xᵢ`: each of the individual measurement values
- `n`: the number of individual measurements in your data set
- Conditions: For the purchase order example, n = 100 gives x̄ = 49.9 seconds.

#### Range (source/course/Les 4/Six Sigma For Dummies.pdf p. 109, S07)

```
R = x_MAX − x_MIN
```
- `R`: the calculated range
- `x_MAX`: the largest observed measurement
- `x_MIN`: the smallest observed measurement
- Conditions: Simplest measure of spread; drawback is that it is greatly influenced by outliers.

#### Individual deviation score (source/course/Les 4/Six Sigma For Dummies.pdf p. 110, S07)

```
xᵢ − x̄
```
- `xᵢ`: any single recorded measurement from your set of data
- `x̄`: the calculated mean of your collected observations
- Conditions: Acts as a numerical 'score' for each data point; negative when xᵢ is below the mean.

#### Squared deviation (source/course/Les 4/Six Sigma For Dummies.pdf p. 110, S07)

```
(xᵢ − x̄)²
```
- `xᵢ`: individual measurement
- `x̄`: calculated mean
- Conditions: Squaring penalizes points farther from the central location disproportionately more than those close (e.g., twice as far away scores four times worse).

#### Summed squared error (SSE) (source/course/Les 4/Six Sigma For Dummies.pdf p. 111, S07)

```
Σ(xᵢ − x̄)²
```
- `Σ`: add up all the individual squared scores
- Conditions: Statisticians call this result the summed squared error, or SSE for short.

#### Variance (source/course/Les 4/Six Sigma For Dummies.pdf p. 112, S07)

```
σ² = Σ(xᵢ − x̄)² / (n − 1)
```
- `σ²`: the variance
- `n`: the total number of data points you have collected
- Conditions: Divided by n−1 rather than n because using the mean (x̄) in the formula loses the independence of one of the collected measurements.

#### Standard deviation (source/course/Les 4/Six Sigma For Dummies.pdf p. 113, S07)

```
σ = √[ Σ(xᵢ − x̄)² / (n − 1) ]
```
- `σ`: the standard deviation
- Conditions: Most commonly used measure of dispersion; units are the same as the original measurements.

#### Sequential range (short-term) (source/course/Les 4/Six Sigma For Dummies.pdf p. 116, S07)

```
R₁ = |x₁ − x₂| ; general: Rᵢ = |xᵢ − xᵢ₊₁|
```
- `Rᵢ`: difference (range) between two sequential measurements
- `xᵢ, xᵢ₊₁`: sequential measurements
- Conditions: Only valid on a sequential set of measurements in the order they were taken.

#### Average sequential range (source/course/Les 4/Six Sigma For Dummies.pdf p. 116, S07)

```
R̄ = [1/(n−1)] Σᵢ₌₁^(n−1) Rᵢ
```
- `R̄`: the average range or difference between sequential points
- Conditions: Average of the between-point ranges.

#### Short-term standard deviation (source/course/Les 4/Six Sigma For Dummies.pdf p. 116, S07)

```
σ_ST = R̄ / 1.128
```
- `σ_ST`: short-term standard deviation
- `R̄`: average sequential range
- `1.128`: special correction factor
- Conditions: Never calculate on anything other than a sequential set of measurements in original order.

#### Long-term standard deviation (source/course/Les 4/Six Sigma For Dummies.pdf p. 118, S07)

```
σ_LT = √[ Σ(xᵢ − x̄)² / (n − 1) ]
```
- `σ_LT`: long-term standard deviation
- Conditions: Identical in form to the overall standard deviation formula (Table 5-3). Book states: 'The calculated short-term variation should always be less than or equal to the calculated long-term variation.'

#### Median position, odd n (source/course/Les 4/Six Sigma For Dummies.pdf p. 127, S07)

```
[(n+1)/2]th value in the rank ordered sequence
```
- `n`: number of observed points in the data set (odd)
- Conditions: Used to find the median of a rank-ordered data set with an odd number of points.

#### Median position, even n (source/course/Les 4/Six Sigma For Dummies.pdf p. 127, S07)

```
average of [n/2]th and [(n/2)+1]th values in the rank order sequence
```
- `n`: number of observed points in the data set (even)
- Conditions: Used to find the median of a rank-ordered data set with an even number of points.

#### Slope (rise over run) (source/course/Les 4/Six Sigma For Dummies.pdf p. 135, S07)

```
rise/run = (y2 − y1) / (x2 − x1)
```
- `(x1,y1), (x2,y2)`: two points on a line
- Conditions: Zero slope = horizontal/flat line; negative slope = line slopes down left to right; positive slope = line slopes up left to right. Used in main effects/scatter plots to compare strength of effect.

#### Rolled throughput yield (generalized) (source/course/Les 4/Six Sigma For Dummies.pdf p. 150, S08)

```
RTY = the product (pi, i=1 to n) of FTYi
```
- `RTY`: rolled throughput yield
- `FTYi`: first time yield of process step i
- `n`: number of process steps
- Conditions: combined overall yield of an entire process stream; can never be greater than the lowest FTY in the system

#### Traditional yield (source/course/Les 4/Six Sigma For Dummies.pdf p. 151, S08)

```
Y = out/in = 1 - scrap/in
```
- `Y`: traditional yield
- `out`: items out
- `in`: items in
- `scrap`: scrapped items
- Conditions: misleading perspective; obscures impact of inspection and rework

#### First time yield (source/course/Les 4/Six Sigma For Dummies.pdf p. 151, S08)

```
FTY = (in - scrap - rework)/in = 1 - (scrap + rework)/in
```
- `FTY`: first time yield
- `in`: items in
- `scrap`: scrapped items
- `rework`: reworked items
- Conditions: likelihood of an item passing through a process successfully the very first time, including effects of inspection, rework and scrap

#### Defects per unit (DPU) (source/course/Les 4/Six Sigma For Dummies.pdf p. 152, S08)

```

```
- `DPU`: defects per unit

#### Defects per opportunity (DPO) (source/course/Les 4/Six Sigma For Dummies.pdf p. 153, S08)

```
DPO = number of defects observed on a unit / number of opportunities on a unit
```
- `DPO`: defects per opportunity
- Conditions: allows fair comparison of defect rates between items of different complexity

#### Defects per million opportunities (DPMO) (source/course/Les 4/Six Sigma For Dummies.pdf p. 155, S08)

- `DPO`: defects per opportunity

#### DPO from DPMO (source/course/Les 4/Six Sigma For Dummies.pdf p. 155, S08)

- `DPO`: defects per opportunity
- `DPMO`: defects per million opportunities

#### Defective parts per million (DPPM) (source/course/Les 4/Six Sigma For Dummies.pdf p. 155, S08)

```
DPPM = DPO x 1,000,000
```
- `DPPM`: defective parts per million, synonymous with DPMO
- `DPO`: defects per opportunity
- Conditions: used when the 'part' is the opportunity, e.g. continuous material or ongoing shipments

#### Rolled throughput yield from DPU (source/course/Les 4/Six Sigma For Dummies.pdf p. 156, S08)

```
RTY = e^(-DPU)
```
- `RTY`: rolled throughput yield
- `e`: mathematical constant, approx 2.71828182845905...
- `DPU`: defects per unit
- Conditions: valid when overall process DPU is relatively low, e.g. less than 0.10 (10 percent)

#### DPU from rolled throughput yield (source/course/Les 4/Six Sigma For Dummies.pdf p. 156, S08)

```
DPU = -ln(RTY)
```
- `DPU`: defects per unit
- `RTY`: rolled throughput yield
- `ln`: natural logarithm
- Conditions: algebraic inverse of RTY = e^-DPU

#### Sigma (Z) score (source/course/Les 4/Six Sigma For Dummies.pdf p. 157, S08)

```
Z = |SL - xbar| / sigma
```
- `Z`: sigma score
- `SL`: specification limit
- `xbar`: mean of the characteristic/process
- `sigma`: standard deviation
- Conditions: use only on a characteristic that is approximately normal

#### Short-term sigma score (source/course/Les 4/Six Sigma For Dummies.pdf p. 158, S08)

```
Z_ST = |SL - xbar| / sigma_ST
```
- `Z_ST`: short-term sigma score
- `SL`: specification limit
- `xbar`: mean
- `sigma_ST`: short-term standard deviation

#### Long-term sigma score (source/course/Les 4/Six Sigma For Dummies.pdf p. 158, S08)

```
Z_LT = |SL - xbar| / sigma_LT
```
- `Z_LT`: long-term sigma score
- `SL`: specification limit
- `xbar`: mean
- `sigma_LT`: long-term standard deviation

#### 1.5-sigma shift (shifted Z) (source/course/Les 4/Six Sigma For Dummies.pdf p. 160, S08)

```
Z_shifted = Z_ST - 1.5
```
- `Z_shifted`: sigma score of the mathematically shifted short-term distribution
- `Z_ST`: short-term sigma score
- Conditions: early Six Sigma practitioners proposed shifting the short-term distribution 1.5 standard deviations closer to the specification limit to approximate long-term defect performance

#### 1.5-sigma shift (long-term from short-term) (source/course/Les 4/Six Sigma For Dummies.pdf p. 160, S08)

```
Z_LT = Z_ST - 1.5
```
- `Z_LT`: long-term sigma score
- `Z_ST`: short-term sigma score
- Conditions: the shifted distribution is treated as defect-wise equivalent to the long-term distribution

#### Short-term capability index Cp (source/course/Les 4/Six Sigma For Dummies.pdf p. 162, S08)

```
Cp = (USL - LSL) / (6 x sigma_ST)
```
- `Cp`: short-term capability index
- `USL`: upper specification limit
- `LSL`: lower specification limit
- `sigma_ST`: short-term standard deviation
- Conditions: use only the short-term standard deviation; a long-term standard deviation gives incorrect results

#### Adjusted short-term capability indices Cpu and Cpl (source/course/Les 4/Six Sigma For Dummies.pdf p. 163, S08)

```
Cpu = (USL - xbar) / (3 x sigma_ST); Cpl = (xbar - LSL) / (3 x sigma_ST)
```
- `Cpu`: upper adjusted capability index
- `Cpl`: lower adjusted capability index
- `USL`: upper specification limit
- `LSL`: lower specification limit
- `xbar`: distribution center
- `sigma_ST`: short-term standard deviation
- Conditions: compares distance from distribution center to each specification limit against half-width of short-term variation

#### Adjusted short-term capability index Cpk (source/course/Les 4/Six Sigma For Dummies.pdf p. 164, S08)

```
Cpk = min(Cpu, Cpl) = min( (USL - xbar)/(3 x sigma), (xbar - LSL)/(3 x sigma_ST) )
```
- `Cpk`: adjusted short-term capability index
- `min`: choose the smallest of the values in parentheses
- `sigma`: as printed (no ST subscript) in first term
- `sigma_ST`: short-term standard deviation, as printed in second term
- Conditions: as printed, the first denominator is shown as '3 sigma' without the ST subscript while the second is '3 sigma_ST'; see ambiguities

#### Long-term capability index Pp (source/course/Les 4/Six Sigma For Dummies.pdf p. 165, S08)

```
Pp = (USL - LSL) / (6 x sigma_LT)
```
- `Pp`: long-term capability index
- `USL`: upper specification limit
- `LSL`: lower specification limit
- `sigma_LT`: long-term standard deviation
- Conditions: same formula as Cp but using sigma_LT in place of sigma_ST

#### Adjusted long-term capability index Ppk (source/course/Les 4/Six Sigma For Dummies.pdf p. 165, S08)

```
Ppk = min( (USL - xbar)/(3 x sigma_LT), (xbar - LSL)/(3 x sigma_LT) )
```
- `Ppk`: adjusted long-term capability index
- `sigma_LT`: long-term standard deviation
- Conditions: same formula as Cpk but using sigma_LT in place of sigma_ST

#### Measurement system variance decomposition (source/course/Les 4/Six Sigma For Dummies.pdf p. 178, S08)

```
sigma^2_OBSERVED = sigma^2_MEASURE + sigma^2_ACTUAL
```
- `sigma^2_OBSERVED`: variance of everything you observe
- `sigma^2_MEASURE`: variance contributed by the measurement system
- `sigma^2_ACTUAL`: actual variance of the process/characteristic

#### Confidence interval for a mean, large sample (source/course/Les 4/Six Sigma For Dummies.pdf p. 190, S08)

```
xbar +/- Z (sigma / sqrt(n))
```
- `xbar`: sample average
- `Z`: sigma value corresponding to desired confidence
- `sigma`: calculated standard deviation from the sample
- `n`: number of data points in the sample
- Conditions: works any time you have more than 30 measurements in your sample

#### Confidence interval for a mean, small sample (source/course/Les 4/Six Sigma For Dummies.pdf p. 192, S08)

```
xbar +/- t (sigma / sqrt(n))
```
- `t`: look-up factor depending on desired confidence level and number of data points (replaces Z)
- `xbar`: sample average
- `sigma`: calculated standard deviation
- `n`: number of data points
- Conditions: used when sample has anywhere from two to 30 data points

#### Confidence interval for a standard deviation (source/course/Les 4/Six Sigma For Dummies.pdf p. 195, S08)

```
[ sqrt( (n-1) sigma^2 / chi^2_LOWER ), sqrt( (n-1) sigma^2 / chi^2_UPPER ) ]
```
- `n`: number of data points
- `sigma`: measured standard deviation
- `chi^2_LOWER`: lower chi-square look-up value (Table 8-2)
- `chi^2_UPPER`: upper chi-square look-up value (Table 8-2)
- Conditions: confidence intervals for standard deviations are usually very wide unless sample size is large

#### Confidence interval for ratio of variances (source/course/Les 4/Six Sigma For Dummies.pdf p. 196, S08)

```
[ (1 / F(n2,n1)) x (sigma1^2/sigma2^2), F(n1,n2) x (sigma1^2/sigma2^2) ]
```
- `F(n2,n1), F(n1,n2)`: look-up F values (Table 8-3)
- `sigma1^2`: variance of numerator distribution (n1 data points)
- `sigma2^2`: variance of denominator distribution (n2 data points)
- Conditions: if the interval contains the value 1, there is no evidence the two distributions have different variances

#### Confidence interval for a proportion (source/course/Les 4/Six Sigma For Dummies.pdf p. 197, S08)

```
y/n +/- Z sqrt( (y/n)(1 - y/n) / n )
```
- `y`: number of successes
- `n`: total number of attempts or trials
- `Z`: sigma value for desired confidence
- Conditions: proportions can never be less than zero or greater than one; adjust interval to natural limits if exceeded

#### Confidence interval for the difference of two proportions (source/course/Les 4/Six Sigma For Dummies.pdf p. 197, S08)

```
y1/n1 - y2/n2 +/- Z sqrt( (y1/n1)(1 - y1/n1)/n1 + (y2/n2)(1 - y2/n2)/n2 )
```
- `y1, n1`: successes and trials for group 1
- `y2, n2`: successes and trials for group 2
- `Z`: sigma value for desired confidence
- Conditions: if interval does not include zero, conclude with the stated confidence that the two proportions differ

#### Correlation coefficient (r) (source/course/Les 4/Six Sigma For Dummies.pdf p. 200, S08)

```
r = (1/(n-1)) x sum_{i=1 to n} [ ((xi - xbar)/sigma_x) x ((yi - ybar)/sigma_y) ]
```
- `r`: correlation coefficient
- `n`: number of data pairs
- `xi, yi`: individual x and y measurements
- `xbar, ybar`: averages of X and Y measurements
- `sigma_x, sigma_y`: standard deviations of X and Y measurements
- Conditions: r is always between -1 and 1; tells only how linear a relationship is, not causation

#### Simple linear regression model (source/course/Les 4/Six Sigma For Dummies.pdf p. 202, S08)

```
Y = beta_0 + beta_1 X + epsilon
```
- `Y`: observed output
- `beta_0`: intercept
- `beta_1`: slope
- `X`: input
- `epsilon`: normal random distribution centered at zero
- Conditions: used for a system with a single output Y and single input X

#### Slope estimate for simple linear regression (source/course/Les 4/Six Sigma For Dummies.pdf p. 203, S08)

```
beta_1 = sum( (xi - xbar) yi ) / sum( (xi - xbar)^2 )
```
- `xi, yi`: paired data points
- `xbar`: average of all X points

#### Residual (source/course/Les 4/Six Sigma For Dummies.pdf p. 204, S08)

```
e_i = Y_i - Yhat_i
```
- `e_i`: residual for data point i
- `Y_i`: observed value
- `Yhat_i`: predicted value from regression equation

#### Total sum of squared error (SSTO) (source/course/Les 4/Six Sigma For Dummies.pdf p. 207, S08)

```
SSTO = sum_{i=1 to n} (Y_i - Ybar)^2
```
- `Y_i`: observed output values
- `Ybar`: average of observed Y

#### Regression sum of squares (SSR) (source/course/Les 4/Six Sigma For Dummies.pdf p. 207, S08)

```
SSR = sum_{i=1 to n} (Yhat_i - Ybar)^2
```
- `Yhat_i`: predicted estimates for the n data points
- `Ybar`: average of observed Y

#### Error sum of squares (SSE) (source/course/Les 4/Six Sigma For Dummies.pdf p. 208, S08)

```
SSE = sum e_i^2 = sum_{i=1 to n} (Y_i - Yhat_i)^2
```
- `e_i`: residual

#### Sum of squares identity (source/course/Les 4/Six Sigma For Dummies.pdf p. 208, S08)

```
SSTO = SSR + SSE
```

#### Coefficient of determination (source/course/Les 4/Six Sigma For Dummies.pdf p. 208, S08)

```
R^2 = SSR / SSTO
```
- `R^2`: coefficient of determination
- Conditions: want this number to be 80 percent or higher

#### Estimated standard deviation of unexplained (epsilon) variation (source/course/Les 4/Six Sigma For Dummies.pdf p. 208, S08)

```
sigmahat_epsilon = sqrt( SSE / (n - 2) )
```
- `sigmahat_epsilon`: estimated standard deviation of epsilon
- `SSE`: error sum of squares
- `n`: number of data points

#### F test for regression model validity (source/course/Les 4/Six Sigma For Dummies.pdf p. 209, S08)

```
sigmahat^2_REG / sigmahat^2_epsilon >= F(2, n-1); where sigmahat^2_REG = SSR and sigmahat^2_epsilon = SSE/(n-2)
```
- `sigmahat^2_REG`: estimate of variance explained by regression model
- `sigmahat^2_epsilon`: estimate of unexplained variance
- `F(2,n-1)`: critical F value
- Conditions: if ratio exceeds the critical F value, conclude with the chosen confidence (e.g. 99 percent) that the derived model is valid

#### General multiple linear regression model (two inputs) (source/course/Les 4/Six Sigma For Dummies.pdf p. 211, S08)

```
Y_i = beta_0 + beta_1 X_1 + beta_11 X_1^2 + beta_2 X_2 + beta_22 X_2^2 + beta_12 X_1 X_2 + epsilon
```
- `beta_0`: overall/offset effect
- `beta_1 X_1, beta_2 X_2`: main effects
- `beta_11 X_1^2, beta_22 X_2^2`: second-order (squared) effects
- `beta_12 X_1 X_2`: interaction effect
- `epsilon`: random unexplained variation, normal, centered at zero
- Conditions: extension of simple linear regression to more than one X

#### Number of runs in a 2^k factorial experiment (source/course/Les 4/Six Sigma For Dummies.pdf p. 222, S08)

```
number of unique runs = 2^k
```
- `k`: number of experimental factors
- Conditions: e.g. k=3 gives 2^3=8 runs; k=2 gives 2^2=4 runs

#### General main/interaction effect formula for a 2^k factorial experiment (source/course/Les 4/Six Sigma For Dummies.pdf p. 227, S08)

```
E_i = (1 / 2^(k-1)) x sum_{j=1 to 2^k} c_(i,j) Y_j
```
- `E_i`: effect i (main or interaction)
- `k`: number of experiment factors
- `c_(i,j)`: coded setting value (+1 or -1, or product of coded values for interactions) for run j
- `Y_j`: response value for run j

#### Expected probability for normal-score ranking of effects (source/course/Les 4/Six Sigma For Dummies.pdf p. 230, S08)

```
P_i = (i - 0.5) / (2^k - 1)
```
- `P_i`: expected probability for rank i
- `i`: rank of the effect (smallest to largest, ties given average rank)
- `k`: number of experiment factors
- Conditions: used as an intermediate step before looking up the corresponding Z value to build a normal probability plot of effects

#### General Y=f(X) equation for a three-factor 2^k experiment (source/course/Les 4/Six Sigma For Dummies.pdf p. 232, S08)

```
Y = beta_0 + beta_1 X_1 + beta_2 X_2 + beta_3 X_3 + beta_12 X_1 X_2 + beta_13 X_1 X_3 + beta_23 X_2 X_3 + beta_123 X_1 X_2 X_3
```
- `beta_0`: overall offset/constant term (computed average of all 2^k experiment runs)
- `beta_i, beta_ij, beta_ijk`: coefficients for main, two-way interaction, and three-way interaction effects
- Conditions: only terms found significant are retained in the simplified equation

#### Coefficient from effect (2^k experiment) (source/course/Les 4/Six Sigma For Dummies.pdf p. 233, S08)

```
beta_i = E_i / 2 (for any significant effect); beta_0 = average of all 2^k experiment run outputs
```
- `beta_i`: regression coefficient for effect i
- `E_i`: calculated effect value
- Conditions: coefficient is half the effect value because the effect spans a coded distance of two (+1 to -1)

- `k`: number of subgroups
- `E2, D3, D4`: look-up constants depending on subgroup size (Table 10-2 constants)

#### Continuous control chart formulas: Averages and Ranges (Xbar-R) (source/course/Les 4/Six Sigma For Dummies.pdf p. 249, S08)

```
Xbar = (Xbar1+Xbar2+...+Xbar_k)/k; Rbar = (R1+R2+...+R_k)/k; UCL_Xbar = Xbarbar + A2 x Rbar; LCL_Xbar = Xbarbar - A2 x Rbar; UCL_R = D4 x Rbar; LCL_R = D3 x Rbar
```
- `k`: number of subgroups
- `A2, D3, D4`: look-up constants depending on subgroup size (Table 10-2 constants)

#### Continuous control chart formulas: Averages and Standard Deviations (Xbar-S) (source/course/Les 4/Six Sigma For Dummies.pdf p. 249, S08)

```
Xbar = (Xbar1+Xbar2+...+Xbar_k)/k; Sbar = (S1+S2+...+S_k)/k; UCL_Xbar = Xbarbar + A3 x Sbar; LCL_Xbar = Xbarbar - A3 x Sbar; UCL_S = B4 x Sbar; LCL_S = B3 x Sbar
```
- `k`: number of subgroups
- `A3, B3, B4`: look-up constants depending on subgroup size (Table 10-2 constants)
- Conditions: subgroup size n > 10

#### p chart (proportion defective) (source/course/Les 4/Six Sigma For Dummies.pdf p. 254, S08)

```
p_i = number defective / n_i (per subgroup); pbar = total number defective / (n1+n2+...+n_k); UCL_i = pbar + 3 sqrt( pbar(1-pbar)/n_i ); LCL_i = pbar - 3 sqrt( pbar(1-pbar)/n_i )
```
- `n_i`: subgroup size (variable, usually > 50)
- `pbar`: overall proportion defective

#### u chart (defects per unit) (source/course/Les 4/Six Sigma For Dummies.pdf p. 254, S08)

- `n_i`: subgroup size (variable)
- `ubar`: overall defects per unit
- Conditions: based on the Poisson distribution; used for defect (count) data. Note: book labels the control limits USL_i/LSL_i in Table 10-3 rather than UCL_i/LCL_i

#### Risk priority number (RPN) (source/course/Les 4/Six Sigma For Dummies.pdf p. 279, S09)

```
RPN = severity rating x probability rating x detection rating
```
- `severity rating`: normalized score for severity of impact of a failure
- `probability rating`: probability score for likelihood the failure will occur
- `detection rating`: probability score for likelihood current controls detect the cause/effect
- Conditions: Used within FMEA (Failure Mode Effects Analysis) to rank failure modes; plotted in a Pareto chart to prioritize attention.

- `RTY`: rolled throughput yield
- Conditions: Average throughput yield at any given step. Example as printed: 10-step process, RTY = 36.8% (0.368); NY = (0.368)**(-10) = 0.9051 (see ambiguities: exponent notation as printed does not algebraically reproduce 0.9051 unless the intended exponent is 1/10, i.e. the 10th root).

- `RTY`: rolled throughput yield
- Conditions: Example: RTY = 70% (0.7) -> repairable: 1+(1-.7)=1.3; scrapped: 1/(.7)=1.43.

#### Determining bias: bias and repeatability (source/course/Les 5/20260619_ottoy_Black Belt in Six Sigma - Measurement System Analysis.pdf p. 32, S10)

```
bias = X_bar_bar - ref.value ; sigma_r = R_bar/d2
```
- `X_bar_bar`: grand average

- `R_bar`: average range

#### Determining bias: t-statistic (source/course/Les 5/20260619_ottoy_Black Belt in Six Sigma - Measurement System Analysis.pdf p. 32, S10)

```
t = (bias - E(bias)) / sigma_r * sqrt(g*m) * d2*/d2
```
- `bias`: computed bias
- `E(bias)`: expected/hypothesized bias
- `sigma_r`: repeatability std dev
- `g`: number of subgroups
- `m`: subgroup size
- `d2*`: conversion factor related to d2 (Patnaik)
- `d2`: range-to-sigma constant

#### Confidence interval for the true gauge bias (source/course/Les 5/20260619_ottoy_Black Belt in Six Sigma - Measurement System Analysis.pdf p. 32, S10)

```
bias - sigma_r * d2/(d2* * sqrt(g*m)) * t_(1-alpha/2,nu) <= E(bias) <= bias + sigma_r * d2/(d2* * sqrt(g*m)) * t_(1-alpha/2,nu)
```
- `bias`: computed bias
- `sigma_r`: repeatability std dev
- `d2`: range-to-sigma constant
- `d2*`: Patnaik conversion factor
- `g`: number of subgroups
- `m`: subgroup size
- `t_(1-alpha/2,nu)`: t-distribution quantile with nu degrees of freedom
- `alpha`: significance level (not numerically specified in the course text)
- Conditions: (1-alpha)x100% confidence interval; the gauge bias is significant if zero does not belong to this interval

#### Patnaik result for the average squared range (source/course/Les 5/20260619_ottoy_Black Belt in Six Sigma - Measurement System Analysis.pdf p. 32, S10)

```
nu * R_bar^2 / (d2*^2 * sigma^2) ~ chi^2(nu)
```
- `nu`: degrees of freedom (can be non-integer)
- `R_bar`: average range
- `d2*`: Patnaik conversion factor
- `sigma`: true repeatability std dev
- Conditions: P.B. Patnaik result (see A.J. Duncan, Quality control and industrial statistics); d2* and nu depend on m (subgroup size) and g (number of subgroups); tabulated in appendix (tabel MSA.pdf)

```
E(chi^2(nu)) = nu  =>  d2*^2 = E(R_bar^2)/sigma^2
```
- `nu`: degrees of freedom
- `d2*`: Patnaik conversion factor
- `R_bar`: average range
- `sigma`: true std dev

#### Average and Range method: model (source/course/Les 5/20260619_ottoy_Black Belt in Six Sigma - Measurement System Analysis.pdf p. 34, S10)

- `X_i..`: operator bias
- `X_..l`: measurement error
- `sigma`: gauge repeatability
- Conditions: k appraisers each measure n parts r times with the gauge; the parts are representative for the process variation

#### Average and Range method: appraiser average (source/course/Les 5/20260619_ottoy_Black Belt in Six Sigma - Measurement System Analysis.pdf p. 34, S10)

```
X_bar_i = (1/nr)*sum_j sum_l X_ijl = X_bar_p + X_i.. + X_bar_bar_r ;  X_bar_bar_r ~ N(0, sigma/sqrt(nr))
```

- `X_bar_p`: fixed number for the given parts
- `X_i..`: operator bias for appraiser i
- `X_bar_bar_r`: average measurement error over all measurements by appraiser i
- `sigma`: gauge repeatability
- `n`: number of parts
- `r`: number of replications

#### Average and Range method: part average (source/course/Les 5/20260619_ottoy_Black Belt in Six Sigma - Measurement System Analysis.pdf p. 34, S10)

```
X_bar_j = X_.j. + X_a + X_bar_bar_r ;  X_bar_bar_r ~ N(0, sigma/sqrt(kr))
```
- `X_bar_j`: average measured value for part j over all appraisers and replications
- `X_.j.`: true part value
- `X_a`: fixed number for the given appraisers
- `X_bar_bar_r`: average measurement error over all measurements of part j
- `sigma`: gauge repeatability
- `k`: number of appraisers

#### Average and Range method: average range (source/course/Les 5/20260619_ottoy_Black Belt in Six Sigma - Measurement System Analysis.pdf p. 34, S10)

```
R_bar_bar = (1/nk) * sum_i sum_j R_ij
```
- `R_bar_bar`: average range over all parts and appraisers
- `R_ij`: range of the r replications for part j by appraiser i
- `n`: number of parts
- `k`: number of appraisers
- Conditions: X_bar_DIFF = range of the appraiser averages; R_bar_p = range of the part averages (defined but not formalized as an equation on this slide)

#### Estimation of EV (repeatability), Average and Range method (source/course/Les 5/20260619_ottoy_Black Belt in Six Sigma - Measurement System Analysis.pdf p. 35, S10)

```
E(R_bar_bar) = d2*sigma  =>  EV = sigma ~= R_bar_bar/d2 = R_bar_bar * K1 ;  K1 = 1/d2
```
- `EV`: equipment variation (repeatability)
- `R_bar_bar`: average range over all parts and appraisers
- `d2`: range-to-sigma constant based on subgroup size = r (number of trials)
- `K1`: 1/d2

#### Estimation of AV (reproducibility), Average and Range method (source/course/Les 5/20260619_ottoy_Black Belt in Six Sigma - Measurement System Analysis.pdf p. 35, S10)

```
E(X_bar_DIFF^2) = d2*^2 * sigma^2(X_bar_i)  =>  sigma^2(X_bar_i) ~= X_bar_DIFF^2/d2*^2 = (X_bar_DIFF*K2)^2  =>  AV = sqrt((X_bar_DIFF*K2)^2 - EV^2/(nr))
```
- `AV`: appraiser variation (reproducibility)
- `X_bar_DIFF`: range of the appraiser averages
- `d2*`: conversion factor based on 1 subgroup of size k (number of appraisers)
- `K2`: 1/d2*
- `EV`: equipment variation
- `n`: number of parts
- `r`: number of replications

#### Estimation of PV (part variation), Average and Range method (source/course/Les 5/20260619_ottoy_Black Belt in Six Sigma - Measurement System Analysis.pdf p. 35, S10)

```
PV = sqrt((R_bar_p*K3)^2 - EV^2/(kr)) ~= R_bar_p * K3 ;  K3 = 1/d2*
```
- `PV`: part variation
- `R_bar_p`: range of the part averages
- `K3`: 1/d2*, based on 1 subgroup of size n (number of parts)
- `EV`: equipment variation
- `k`: number of appraisers
- `r`: number of replications
- Conditions: if process variation is large compared to equipment variation and the selected parts properly represent process variation, PV simplifies to R_bar_p*K3

#### GRR and TV combination, Average and Range method (source/course/Les 5/20260619_ottoy_Black Belt in Six Sigma - Measurement System Analysis.pdf p. 35, S10)

```
GRR^2 = EV^2 + AV^2 ;  TV^2 = GRR^2 + PV^2 ;  %GRR = GRR/TV x 100%
```
- `GRR`: gauge repeatability & reproducibility
- `EV`: equipment variation
- `AV`: appraiser variation
- `TV`: total variation
- `PV`: part variation
- `%GRR`: percent GRR relative to total variation

#### ANOVA method: two-way ANOVA table (without interaction) (source/course/Les 5/20260619_ottoy_Black Belt in Six Sigma - Measurement System Analysis.pdf p. 36, S10)

```
Factor a=appraiser: SSa, df_a=(k-1), MSa=SSa/df_a, Fa=MSa/MSe. Factor p=part: SSp, df_p=(n-1), MSp=SSp/df_p, Fp=MSp/MSe. Error e: SSe, df_e=nk(r-1)+(k-1)(n-1), MSe=SSe/df_e. Total: SST, df=nkr-1
```
- `k`: number of appraisers

- `r`: number of replications

```
EV = sqrt(MSe) ; AV = sqrt((MSa - EV^2)/(nr)) ; PV = sqrt((MSp - EV^2)/(kr))
```

#### ANOVA method: two-way model without interaction (fitted value and residual) (source/course/Les 5/20260619_ottoy_Black Belt in Six Sigma - Measurement System Analysis.pdf p. 36, S10)

```
X_hat_ij = X_bar_bar + (X_bar_i - X_bar_bar) + (X_bar_j - X_bar_bar) ;  X_ijl - X_hat_ij = X_ijl - X_bar_i - X_bar_j + X_bar_bar
```

```
MSe = sum_i sum_j sum_l (X_ijl - X_hat_ij)^2 / [nk(r-1) + (n-1)(k-1)] = EV^2 ;  MSa = nr*sum_i(X_bar_i - X_bar_bar)^2 / (k-1) = nr*(AV^2 + EV^2/(nr))
```

### 20260619_ottoy_Theoretical background of a GRR study.pdf

#### Distribution of the sample average (source/course/Les 5/20260619_ottoy_Theoretical background of a GRR study.pdf p. 1, S10)

```
E(X_bar) = E(X) ;  sigma^2(X_bar) = sigma^2(X)/n
```
- `X_bar`: average of a sample of X-values
- `X`: random variable with mean E(X) and variance sigma^2(X)
- `n`: sample size
- Conditions: if n sufficiently large, X_bar follows approximately a normal distribution (Central Limit Theorem)

#### Distribution of the sample range (source/course/Les 5/20260619_ottoy_Theoretical background of a GRR study.pdf p. 1, S10)

```
E(R) = d2*sigma ;  sigma(R) = d3*sigma
```
- `R`: range of a sample of X-values
- `sigma`: std dev of normally distributed X (mean mu)
- `d2`: constant depending on sample size n
- `d3`: constant depending on sample size n
- Conditions: X normally distributed with mean mu and variance sigma^2; example values given: d2 = 2,326 and d3 = 0,864 for 'a sample of size' (the sample size value itself is missing/omitted in the printed text - see ambiguities)

#### Mean and variance of a chi-square distribution (source/course/Les 5/20260619_ottoy_Theoretical background of a GRR study.pdf p. 1, S10)

```
E(X) = n ;  sigma^2(X) = 2n
```
- `X`: random variable following a chi-square distribution
- `n`: degrees of freedom

#### Distribution of the average squared range (source/course/Les 5/20260619_ottoy_Theoretical background of a GRR study.pdf p. 1, S10)

```
nu*R_bar^2 / (d2*^2*sigma^2) ~ chi^2(nu) ;  E(nu*R_bar^2/(d2*^2*sigma^2)) = nu  =>  E(R_bar^2) = d2*^2*sigma^2
```
- `R_bar`: average range based on g samples (subgroups) of size m
- `sigma`: std dev of normally distributed X
- `nu`: degrees of freedom, depends on m and g
- `d2*`: constant depending on m and g
- `g`: number of subgroups
- `m`: subgroup size
- Conditions: example: for 5 samples of size 3, d2*=1,73857 and nu=9,3; d2* -> d2 as g -> infinity

#### Calculation of EV (theoretical derivation) (source/course/Les 5/20260619_ottoy_Theoretical background of a GRR study.pdf p. 1, S10)

```
E(R_bar) = E(R) = d2*sigma = d2*EV  =>  EV = R_bar/d2
```
- `EV`: repeatability (equipment variation)
- `R_bar`: average range over all parts and appraisers
- `d2`: range-to-sigma constant, subgroup size = r (replications)
- Conditions: assumes EV is independent from the appraiser and part

#### Calculation of AV (theoretical derivation) (source/course/Les 5/20260619_ottoy_Theoretical background of a GRR study.pdf p. 1, S10)

```
E(X_bar_DIFF^2) = d2*^2*sigma^2(X_bar_i) ;  sigma^2(X_bar_i) = sigma^2(X_i..) + sigma^2(X_bar_r) = AV^2 + sigma^2/(nr) = AV^2 + EV^2/(nr) ;  AV^2 = X_bar_DIFF^2/d2*^2 - EV^2/(nr)
```
- `X_bar_DIFF`: range of the appraiser averages X_bar_i
- `d2*`: conversion factor based on 1 subgroup of size k (number of appraisers)
- `X_i..`: operator bias
- `X_bar_r`: average measurement error for operator i (all parts, all replications)
- `AV`: reproducibility (appraiser variation)
- `EV`: repeatability
- `n`: number of parts
- `r`: number of replications
- Conditions: for the average measurement X_bar_i of operator i (all parts n and replications r): X_bar_i = X_bar_p + X_i.. + X_bar_r

#### Calculation of TV and %GRR (theoretical derivation) (source/course/Les 5/20260619_ottoy_Theoretical background of a GRR study.pdf p. 2, S10)

```
TV^2 = PV^2 + GRR^2 = PV^2 + AV^2 + EV^2 ;  %GRR = GRR/TV
```
- `TV`: total variation
- `PV`: part variation
- `GRR`: gauge repeatability and reproducibility
- `AV`: appraiser variation
- `EV`: equipment variation
- Conditions: PV calculated in the same way as AV
